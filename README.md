# Image Editor

A browser-based Image Editor built using HTML, CSS, and JavaScript. This project allows users to edit images using interactive filters and a simple user interface.

## Features

- Image editing in the browser
- Brightness adjustment
- Contrast adjustment
- Interactive filter controls
- Simple and user-friendly interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
